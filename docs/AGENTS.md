# docs 目录指南

## 用途

存放技术说明，**不是提示词正文**。提示词正文只维护在仓库根目录。

## 目录内容

- `目录代码审查主编排提示词_技术说明.md`：根目录 `目录代码审查_主编排_v3.md` 的**外部依赖说明**。记录所依赖的 Orca CLI 版本、已实测核对过的命令与参数（含核对日期）、以及 Orca 升级后需要重核的三类事项。它不是审查报告，不含历史问题清单。

## 约束

- 新增文件时同步更新本索引。
- 文件名使用中文描述性命名，与根目录提示词文件名区分，避免误当成生效提示词。
- **本目录不放历史问题清单**：问题一旦修复，对应的清单即失效，留着只会让读者误以为当前仍有该问题。需要留痕的内容收敛为「当前版本依赖什么、怎么复核」。
- 不在本目录存放凭据、token、cookie、数据库文件或任何项目敏感数据。

## 验证

本仓库无构建或测试命令。文档改动后的核对方式为人工确认：根目录 `AGENTS.md` 的索引条目与本目录实际文件一致；技术说明中的 Orca 版本号与 `orca --version` 输出一致。
